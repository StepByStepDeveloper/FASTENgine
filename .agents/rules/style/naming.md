# Naming Conventions

| Entity | Convention | Example |
|--------|------------|---------|
| Files | snake\_case | `engine_core.cpp` / `engine_core.h` |
| Classes/Structs/Enums/Typedefs | PascalCase | `Renderer` |
| Functions/Methods | PascalCase | RenderFrame() |
| Local Variables/Parameters | snake\_case | `delta_time` |
| Class Data Members | snake\_case\_ | `buffer_size_` |
| Constants | kPascalCase | `kMaxBufferSize` |
| Namespaces | snake\_case | `fast_engine` |
