# FASTENgine API reference

This reference is generated by Doxygen from the engine sources. The comment
rules every entity here follows live in
`docs/development/conventions/style/documentation.md`; the build conventions
live in `docs/development/conventions/docs.md`.

- Architecture documentation (arc42, AsciiDoc): `docs/arc42/` — build with `doit docs`.
- Architecture as pages: the arc42 document is converted into Doxygen pages by
  `tools/render_arc42_pages.py` (run by `doit docs`) — edit the AsciiDoc
  sources, never the converted pages.
- Modules: the "Modules" group tree is defined in `docs/api/groups.dox` and
  mirrors Section 5 of the architecture document.
- Warnings: this build runs with `WARN_IF_UNDOCUMENTED = YES` and `EXTRACT_ALL = NO`,
  so a warning means an entity is missing its documentation block.

Build: `doit docs` (or `doxygen docs/api/Doxyfile` from the repository root).
