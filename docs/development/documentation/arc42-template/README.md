# arc42 template (vendored copy)

The official arc42 template, English AsciiDoc sources: the manual of *what an arc42 document must contain*, section by section. The working document of this repository ([`docs/arc42/`](../../../../docs/arc42/arc42.adoc)) was created from this template and shows the same help texts while it is in template state.

- **Source**: the arc42 template, [arc42.org](https://arc42.org) ([arc42/arc42-template](https://github.com/arc42/arc42-template)) — English / AsciiDoc, version per `version.properties`.
- **License**: Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0) — the template's own terms. Attribution: arc42 by Dr. Gernot Starke and contributors.
- **State**: a frozen vendored copy for reference — not built by `doit docs`, and excluded from the [tree checker](../../documentation/arc42.md)'s include/image/link scans by design: it references upstream files this copy does not carry. Do not edit it to fix a render; update the copy wholesale when the upstream template moves.
- Read `arc42-template.adoc` (the master) and `adoc/01…12_*.adoc` (the per-section guidance) — they are the same texts the working document shows through `:arc42help:`.
