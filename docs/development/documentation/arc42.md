# The arc42 document

`docs/arc42/` holds the architecture documentation of FASTENgine: the arc42 template filled with the project's architecture. This guide is the procedure; the binding rules are the [Documentation System](../conventions/docs.md); the section-by-section manual of required content is the vendored official template, [arc42-template/](arc42-template/README.md).

## The tree

| Path | Owns |
|:--|:--|
| `arc42.adoc` | The master — includes `config.adoc` and the twelve sections in order |
| `config.adoc` | Shared attributes: `:toc:`, `:imagesdir:`, `:arc42help:` |
| `about-arc42.adoc` | Provenance: template version, license, adaptation note |
| `sections/01…12_*.adoc` | One file per arc42 section; stable names, anchors `[[section-*]]` |
| `adr/` | The decision records — see [Architecture decisions](adr.md) |
| `diagrams/*.puml` | PlantUML sources — the only editable form of a diagram |
| `images/` | Renders (`.svg`, generated by `doit diagrams`) and committed static images |

## Filling a section

1. Pick the owning section file in `docs/arc42/sections/` — never create a second file for a section.
2. Keep the heading structure; replace the `**<...>**` placeholders with content. A filled section carries no placeholders of its own.
3. Keep the `ifdef::arc42help[]` blocks while the document is a template — they are the arc42 guidance. When the last section is filled, remove `:arc42help:` from `config.adoc` and delete the dead help blocks.
4. Diagrams: edit `diagrams/<name>.puml`, run `doit diagrams`, and reference the render (`image::<name>.svg[alt]`) — never the `.puml`, never an absolute path.
5. Cross-references: `<<adr-NNNN,ADR-NNNN>>` for decisions included into Section 9; `xref:path[text]` for other files.
6. Section 9 is generated territory — its index and include list are written by `tools/new_adr.py` only.
7. Verify: `doit docs_check` and `doit docs`; the rendered page is `build/docs/arc42/arc42.html`.

## What each section must contain

arc42 defines the twelve sections; the vendored [official template](arc42-template/README.md) carries the same help texts the working document shows while `:arc42help:` is on — read it section by section when the required content is unclear. The working document is in template state: placeholders and help blocks are expected until a section is filled.

## Pitfalls

- Markdown is not allowed under `docs/arc42/` — the AsciiDoc sources are the contract.
- The renders in `images/` are generated: never commit or hand-edit them; `check_docs` accepts a referenced image backed by a `.puml` source even before the first render.
- Removing `:arc42help:` while placeholders remain is a violation.
- The Doxygen architecture pages are converted from these sources by `tools/render_arc42_pages.py` (inside `doit docs`); edit the sources, never the converted pages.

## Verification

`doit docs_check` reports PASS and `doit docs` exits 0; the edited section appears numbered in `build/docs/arc42/arc42.html` and, converted, among the Doxygen pages.
